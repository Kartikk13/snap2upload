# Privacy Policy — Snap2Upload

**Last updated: October 4, 2026**

Snap2Upload is an independent third-party Chrome extension.

## Information handled by the extension

When a user activates the screenshot shortcut, Snap2Upload captures the visible area of the currently active browser tab.

The captured image is transferred to an already-open supported ChatGPT webpage so that it can be attached to the user's conversation.

## Developer-controlled data collection

Snap2Upload does not operate a developer-controlled backend or analytics server for the screenshot workflow.

The project does not intentionally collect, sell, or store users' screenshots on developer-controlled infrastructure.

## User responsibility

A screenshot may contain personal, confidential, financial, work-related, or other sensitive information.

Users should review the screenshot and the destination conversation before sending it.

Once the user sends an attachment to a third-party service such as ChatGPT, the handling of that content is governed by that service's applicable terms and privacy policies.

Snap2Upload does not control how a third-party service handles content after the user submits it.

## Permissions

Snap2Upload requests only the permissions required by its current implementation:

- `activeTab` — access to the active tab following the user's invocation of the screenshot command.
- `commands` — support for the keyboard shortcut.

The extension also declares host access for supported ChatGPT pages so its content script can receive screenshots and attach them to the conversation.

## Changes to this policy

If the extension's data practices materially change, this policy will be updated accordingly.

## Contact

For privacy questions or concerns, please use the contact information provided with the project's public repository.
